# COREXHIVES Streamlit Dashboard

## Publish it so it opens on any phone
1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt` to the repository root.
3. Open https://share.streamlit.io/ and sign in.
4. Select **Create app**, choose your repository and branch, and set the main file path to `app.py`.
5. Deploy. Share the public Streamlit URL with your teachers. It opens in mobile and desktop browsers.

## Important
The dashboard is mobile-responsive. Current measurements, graph and statuses are sample demonstration data, not live hardware readings. Replace them with actual ESP32, sensor and model outputs after integration.
